# Simple VOCA App

「Simple VOCA App」は、写真やイラスト、そして自分の声を録音したボタンを自由に配置して、オリジナルの音声出力可能なコミュニケーションボードをブラウザ上で作成・再生できるWebアプリです。

PC・タブレット端末・スマートフォンからURL `https://iamsam174.github.io/SimpleVOCA/` にアクセスするだけですぐに利用できます。

---

## 🌟 主な特徴

* **カスタマイズ自在なマス数設定**
  1✕1 から 最大 6✕6 マスまで、利用者の認知能力や運動機能に合わせて自由に行・列の数を設定できます。
* **かんたんボタン編集**
  身の回りの写真（機器のカメラで撮影・写真アプリ内のファイル選択）と、その場でマイク録音した音声をボタンに貼り付けることができます。
* **オートフィット文字サイズ**
  マスの数（画面の分割数）に応じて、ボタンの文字サイズが自動で最適な大きさに調整されます。
* **拡大表示＆音声再生（再生モード）**
  再生画面でボタンを押すと、写真と文字が画面いっぱいにズームアップされ、同時に録音された音声が再生されます。視覚的・聴覚的なフィードバックが明確です。
* **安心のローカル保存**
  作ったボードはブラウザ（LocalStorage）に自動で保存されるため、毎回作り直す必要がありません。

## 🚀 使い方（導入手順）

GitHub Pages等で公開されているURL、またはダウンロードした `index.html`（旧名: `SimpleVOCA_v1.0.1.html`）をブラウザで開くだけで起動します。

### 1. コミュニケーションボードを作る
1. トップ画面で **［コミュニケーションボードを作る］** をタップします。
2. 利用者に合わせた「たて（行）」と「よこ（列）」のマス数を選び、**［ボードを作成する］** を押します。
3. 空白のマス（＋マーク）をタップすると、設定モーダルが開きます。
4. 写真の選択、ことばの入力、マイクでの音声録音（※）を行い、**［決定］** を押します。
5. 配置が終わったら、右上の **［かんせい（保存）］** を押すとブラウザに保存されます。

> 💡 **※ マイク録音のコツ**
> 最初に［マイクの使用を許可する］を押し、ブラウザのアクセス許可ポップアップで「許可」を選択してください。その後、ボタンが「🔴 録音をはじめる」に変わります。

### 2. ボードをつかう（再生モード）
1. トップ画面で **［作成済みコミュニケーションボード］** をタップします。
2. 保存されたボードが表示されます。ボタンをタップすると、画面いっぱいに拡大表示され、録音した音声が流れます。
3. 拡大画面（白い背景部分）のどこかをタップすると、元のボード画面に戻ります。

### 3. 直す・修正する
* トップ画面の **［作成済みボードを編集する］** から、いつでも内容の追加や変更、マス数の変更が可能です。

## 🛠 動作環境

HTML5、JavaScript、Web Audio APIが動作する一般的なブラウザで動作します。

* **パソコン:** Google Chrome / Microsoft Edge / Safari
* **タブレット:** iPad (Safari / Chrome / Edge) / iPhone (Safari / Chrome / Edge) / Android (Chrome)

> ⚠️ **iPad / iPhone (iOS) でご利用の際の注意点**
> 端末の「ファイル」アプリから直接HTMLファイルを開いた場合、Appleのセキュリティ制限によりマイク録音機能が動作しない場合があります。
> その場合は、**GitHub Pages** 等を使ってWebサーバー上に公開した `https://iamsam174.github.io/SimpleVOCA/` にアクセスすると、マイク機能が正常に動作します。
