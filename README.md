# Simple VOCA App

「Simple VOCA App」は、画像（写真やイラストなど）に自分の声を録音したボタンを画面上に配置して、それをタップまたは左クリックすることで音声を出すことができるコミュニケーションボードをブラウザ上で作成・再生できるWebアプリです。

PC・タブレット端末・スマートフォンからURL `https://iamsam174.github.io/SimpleVOCA/` にアクセスするだけですぐに利用できます。

---

## 🌟 主な特徴

* **カスタマイズ自在なマス数設定**
  1✕1 から 最大 6✕6 マスまで、利用者の認知能力や運動機能に合わせて自由に行・列の数を設定できます。
* **かんたんボタン編集**
  身の回りの写真（使用するICT機器のカメラで撮影または写真アプリ内の画像ファイル選択）と、その場でマイク録音した音声をボタンに貼り付けることができます。
  ※ICT機器のカメラを使用した写真撮影はiPhone・iPad・Androidのみ対応しています
* **オートフィット文字サイズ**
  マスの数（画面の分割数）に応じて、ボタンの文字サイズが自動で最適な大きさに調整されます。
* **拡大表示＆音声再生（再生モード）**
  再生画面でボタンを押すと、写真と文字が画面いっぱいにズームアップされ、同時に録音された音声が再生されます。視覚的・聴覚的なフィードバックが明確です。
* **安心のローカル保存**
  作ったボードはブラウザ（LocalStorage）に自動で保存されるため、毎回作り直す必要がありません。

## 🚀 使い方（導入手順）

GitHub Pages等で公開されているURL `https://iamsam174.github.io/SimpleVOCA/` をブラウザで開くだけで起動します。

### 1. コミュニケーションボードを作る
1. トップ画面で **［コミュニケーションボードを作る］** をタップします。
2. 利用者に合わせた「たて（行）」と「よこ（列）」のマス数を選び、**［ボードを作成する］** を押します。
3. 空白のマス（＋マーク）をタップすると、設定モーダルが開きます。
4. 写真の選択、ボタンのことば（なまえ）の入力、マイクでの音声録音（※）を行い、**［決定］** を押します。
5. 配置が終わったら、右上の **［かんせい（保存）］** を押すとブラウザに保存されます。

> 💡 **※ マイク録音のコツ**
> 最初に［マイクの使用を許可する］を押し、ブラウザのアクセス許可ポップアップで「許可」を選択してください。その後、ボタンが「🔴 録音をはじめる」に変わります。

### 2. ボードをつかう（再生モード）
1. トップ画面で **［作成済みコミュニケーションボード］** をタップします。
2. 保存されたボードが表示されます。ボタンをタップすると、画面いっぱいに拡大表示され、録音した音声が流れます。
3. 拡大画面（白い背景部分）のどこかをタップすると、元のボード画面に戻ります。

### 3. 作成済みコミュニケーションボードを修正する
* トップ画面の **［作成済みボードを編集する］** から、コミュニケーションボードの削除、ボタンの内容（画像、録音音声、ボタンの名前）の修正、ボタンの削除が可能です。

## 🛠 動作環境

HTML5、JavaScript、Web Audio APIが動作する一般的なブラウザで動作します。

* **パソコン:** Google Chrome / Microsoft Edge / Safari (Macのみ)
* **タブレット:** iPad (Safari / Chrome / Edge) / Android (Chrome)
* **スマートフォン:** iPhone (Safari / Chrome / Edge) / Android (Chrome)

## ⚠️ **iPad (iPadOS)  / iPhone (iOS) でご利用の際の注意点**
* Safariで `https://iamsam174.github.io/SimpleVOCA/` にアクセスし、共有アイコン＞ホーム画面に追加＞Webアプリとして開くON にしてホーム画面に追加すると、作ったコミュニケーションボードのデータが端末のブラウザの LocalStorage（ローカルストレージ）に保存されて勝手に削除されなくなって便利です。
* このアプリは、コミュニケーションボードのデータをブラウザの LocalStorage（ローカルストレージ） という場所に保存しています。
* iPadやiPhoneの内部ストレージが、たとえ「あと10GB空いている」状態であっても、ブラウザ（SafariやChrome）はセキュリティとデータ肥大化防止の観点から、「1つのWebサイト（URL）がLocalStorageに保存できるデータは最大5MBまで」と制限しています。
### **「トリミングした写真」や「短めの録音」を使いましょう**
* 5MBを超えてさらに新しいコミュニケーションボードを保存しようとすると、プログラム側でエラーが起き、それ以上の保存（写真や録音の追加）ができなくなり、「保存できません」という意味のメッセージが表示されて、次に進めなくなります。
* カメラアプリで撮影した写真や、高画質なイラストをそのままボタンに貼り付けると、写真1枚だけで 1MB〜3MB に達することがあり、そのままの画質だと、写真2〜3枚を貼り付けただけで5MBの限界に達してしまい、次のボードが保存できなくなります。
* 写真をボタンに登録する前に、デバイスの写真編集機能で「ボタンに使う部分だけを小さく正方形に切り抜いた（トリミングした）写真」を用意してからアプリで選択してもらうと、データ量が10分の1以下（数MB ➔ 数十〜数百KB）になり、容量が節約できます。
* 録音する音声データ（Base64形式）は、1回3秒〜5秒程度の短い発話であれば、1個あたりおよそ 50KB〜80KB ほどになりますが、長いと LocalStorage を圧迫して保存できなくなり、「保存できません」という意味のメッセージが表示されて、次に進めなくなります。
